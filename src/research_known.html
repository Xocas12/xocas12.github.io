Statistical forensics

open source results

Tests for manipulation in reported figures: a shared method library plus one repo per domain. Each method is calibrated on cases with a known answer before it's applied anywhere new.

  • forensic-elections reproduces two published falsification signatures on 192,924 Russian precinct protocols. One is an excess of integer turnout and vote-share percentages (z from 2.3 to 12.2). The other is a second turnout mode, found with Silverman's critical-bandwidth test (p = 0.001, 999 bootstrap draws). The integer excess grows with precinct size, which rules out small-precinct arithmetic. Demo below.
  • forensics-core has the methods: digit tests, threshold bunching, flow reconciliation with chi-square gross-error tests, and positive-unlabelled learning, with 840 tests. A red-team module generates honest data built to trigger each detector; a 5% OCR glyph-confusion rate makes the last-digit test fire on 54 of 60 clean tables.
  • psephos is a CLI auditor for precinct results. Every flag is reported with its innocent explanations, and multiple hypotheses are corrected with Benjamini-Hochberg. It has no first-digit Benford test because that test rejected 100 of 100 honest simulated elections.
  • forensic-economy applies the toolkit to SEC enforcement cases, Chinese provincial GDP and Soviet statistics. The data audits are done; the analysis hasn't run.

These tests flag patterns worth a closer look. They don't establish fraud, and each README says so.

contagion-lab · interbank contagion

private

A simulation lab on how interbank network structure affects whether one bank failure cascades. Four propagation engines share one interface: Furfine sequential default, Eisenberg-Noe clearing with Rogers-Veraart default costs, differential DebtRank, and fire sales on common sovereign holdings. A result counts only where the engines agree.

  • Bilateral exposures aren't public, so they're reconstructed three ways from published totals (maximum entropy, minimum density, a fitness ensemble), and each experiment reports how sensitive it is to that choice.
  • Loaders for BIS, IMF, EBA, BCBS and FR Y-15 are tested against fixtures built from real rows, each with a negative control. CET1 for the 22 non-EU G-SIBs is transcribed from the banks' own filings, sourced per row.

Loaders are verified and the first real network build has 141 banks. No experiments have run on it yet. E1, a replication of Espinosa-Vega and Solé (2010) on the country-level network, is coded and tested, but its results aren't published. 460 tests.

tenk-risk-text · 10-K text as a risk signal

private · pre-registered

Two pre-registered hypotheses: firms that rewrite their risk factors see higher volatility the following year, and unusual hedging language in MD&A precedes restatements. Both were fixed before any outcome data was merged. The code won't unseal the confirmation years unless the pre-registration file is committed and unchanged; it logs the commit hash and runs the confirmatory test once.

  • An exact Lazy Prices similarity replication, a sentence-level new-share measure, and a hedging classifier that falls back to a curated word list if LLM labels disagree with blind hand labels (Cohen's κ below 0.6).
  • With only ten fiscal-year clusters, inference uses t(9) and a Bonferroni split across the two hypotheses. 186 tests.

Synthetic data only so far. The 2005–2020 EDGAR corpus (3.5 GB) is downloaded and split into 47 million sentences, and 39,563 of 42,268 later 10-Ks are crawled. Nothing gets unsealed until the corpus is complete.

gosplan-env · planning incentives and misreporting

open source · in progress

A multi-agent RL environment where learning enterprises face a rule-based planner with a notched bonus, a target ratchet and audits, to see whether Soviet-style misreporting emerges from the incentives alone. A test fails the build if the environment hard-codes any pathology, and a CI guard keeps early code away from the held-out phenomena.

  • Built and run: the environment, exact dynamic programming, independent PPO, a HiGHS oracle, a JAX port of the step function (NumPy parity to about 1e-13), and every pre-registered gate experiment.
  • From the labelled studies: with three times the training budget the learned economy collapses to near-zero output, and an evaluation shows it is a coordination trap. A lone producer loses, and everyone producing is better off.

Gates G2 and G3 did not pass. PPO doesn't recover the single-enterprise DP optimum, and the learned populations aren't converged, so everything after G3 is reported as a labelled study. The LLM study hasn't run.
